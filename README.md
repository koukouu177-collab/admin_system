## Description

ADMIN-SYSTEM regroupe plus de 1000 menus et outils pour gérer, surveiller et diagnostiquer des systèmes Linux, des réseaux et des équipements de télécommunications. Le script fournit des liens vers les logiciels officiels et permet d'automatiser les tâches courantes d'administration.

## Fonctionnalités principales

- Dashboard système en temps réel
- Gestion des utilisateurs et groupes
- Gestion des services systemd
- Surveillance CPU, RAM, disque, réseau
- Gestion des pare-feu (iptables/nftables/ufw)
- Configuration réseau (IP, DNS, routes)
- Outils de télécommunication (VoIP, SNMP, SMS)
- Gestion des packages
- Sauvegarde et restauration
- Gestion des processus
- Logs système
- Outils de sécurité basiques
- Liens vers les logiciels professionnels

## Installation

```bash
pip install -r requirements-admin-system.txt
```

## Utilisation

```bash
python3 ADMIN-SYSTEM.py
```

## Prérequis

- Python 3.8+
- Linux (Ubuntu/Debian/CentOS/Fedora/Arch)
- Droits sudo pour certaines actions
